# Monte Carlo VaR

## 1. Что решает метод

Monte Carlo VaR оценивает максимальный ожидаемый убыток портфеля на заданном горизонте при заданном уровне доверия.

Например:

```text
Портфель российских акций: 10 000 000 RUB
Горизонт: 1 день
Уровень доверия: 95%
VaR95 = 320 000 RUB
```

Это означает:

```text
С вероятностью 95% дневной убыток не превысит 320 000 RUB.
Или иначе:
примерно в 5% худших сценариев убыток будет больше 320 000 RUB.
```

VaR отвечает на вопрос:

```text
Где находится граница плохих сценариев?
```

Он не говорит, насколько плохими будут сценарии за этой границей. Для этого используется CVaR.

---

## 2. Математическая идея

Пусть:

- \(V_0\) — текущая стоимость портфеля;
- \(R_p\) — случайная доходность портфеля за период;
- \(L\) — убыток портфеля.

Тогда:

\[
L = -V_0 R_p
\]

Если доходность положительная, убыток отрицательный, то есть это прибыль.

Для уровня доверия \(\alpha\), например \(0.95\), VaR определяется как квантиль распределения убытков:

\[
VaR_{\alpha} = q_{\alpha}(L)
\]

Для практического риск-менеджмента часто удобнее думать так:

\[
P(L > VaR_{\alpha}) = 1 - \alpha
\]

Например:

\[
P(L > VaR_{0.95}) = 0.05
\]

---

## 3. Почему здесь нужен Monte Carlo

Если портфель простой и доходности нормальные, VaR можно посчитать аналитически.

Но для реального портфеля часто есть:

- много акций;
- разные веса;
- нелинейные инструменты;
- не нормальное распределение доходностей;
- гэпы;
- толстые хвосты;
- стрессовые сценарии;
- зависимость между активами.

Monte Carlo позволяет не искать закрытую формулу, а сгенерировать много сценариев и посмотреть распределение результата.

## 6. Реализация на Python

Этот пример использует синтетические данные. В реальном проекте блок генерации `returns` нужно заменить на реальные доходности MOEX.

```python
import numpy as np


def monte_carlo_var(
    returns: np.ndarray,
    weights: np.ndarray,
    portfolio_value: float,
    confidence_level: float = 0.95,
    n_simulations: int = 100_000,
    random_state: int = 42,
) -> float:
    """
    Monte Carlo VaR для линейного портфеля акций.

    returns:
        Матрица исторических дневных доходностей.
        Shape: [n_days, n_assets]

    weights:
        Веса активов в портфеле.
        Shape: [n_assets]

    portfolio_value:
        Стоимость портфеля в рублях.

    confidence_level:
        Уровень доверия VaR, например 0.95 или 0.99.

    n_simulations:
        Количество Monte Carlo сценариев.
    """

    rng = np.random.default_rng(random_state)

    mean = returns.mean(axis=0)
    cov = np.cov(returns.T)

    simulated_asset_returns = rng.multivariate_normal(
        mean=mean,
        cov=cov,
        size=n_simulations,
    )

    simulated_portfolio_returns = simulated_asset_returns @ weights

    losses = -simulated_portfolio_returns * portfolio_value

    var = np.quantile(losses, confidence_level)

    return float(var)


if __name__ == "__main__":
    np.random.seed(42)

    tickers = ["SBER", "LKOH", "YDEX", "T", "VKCO"]
    n_days = 1500
    n_assets = len(tickers)

    # Синтетические дневные доходности.
    # Для реального проекта заменить на доходности из MOEX / T-Invest / собственной БД.
    returns = np.random.normal(
        loc=0.0004,
        scale=0.025,
        size=(n_days, n_assets),
    )

    weights = np.array([0.30, 0.25, 0.20, 0.15, 0.10])
    portfolio_value = 10_000_000

    var_95 = monte_carlo_var(
        returns=returns,
        weights=weights,
        portfolio_value=portfolio_value,
        confidence_level=0.95,
        n_simulations=100_000,
    )

    var_99 = monte_carlo_var(
        returns=returns,
        weights=weights,
        portfolio_value=portfolio_value,
        confidence_level=0.99,
        n_simulations=100_000,
    )

    print(f"VaR95: {var_95:,.0f} RUB")
    print(f"VaR99: {var_99:,.0f} RUB")
```

Ковариационная матрица строится по транспонированной матрице доходностей:

```python
cov = np.cov(returns.T)
```

В таком виде строки соответствуют активам, а столбцы — историческим наблюдениям.

## 7. Более практичная версия без нормального распределения

Если не хочется предполагать нормальность доходностей, можно использовать исторический bootstrap.

Идея:

```text
Берем случайные исторические дни.
Используем реальные совместные движения акций в эти дни.
Считаем доходность портфеля.
Повторяем много раз.
```

```python
import numpy as np


def historical_bootstrap_var(
    returns: np.ndarray,
    weights: np.ndarray,
    portfolio_value: float,
    confidence_level: float = 0.95,
    n_simulations: int = 100_000,
    random_state: int = 42,
) -> float:
    rng = np.random.default_rng(random_state)

    n_days = returns.shape[0]

    sampled_day_indices = rng.integers(
        low=0,
        high=n_days,
        size=n_simulations,
    )

    sampled_returns = returns[sampled_day_indices]

    portfolio_returns = sampled_returns @ weights

    losses = -portfolio_returns * portfolio_value

    return float(np.quantile(losses, confidence_level))
```

Этот вариант часто лучше для первого исследования, потому что:

- сохраняет реальные корреляции между акциями;
- не требует предположения нормальности;
- прост в реализации;
- хорошо объясняется в диссертации или техническом документе.

## 8. Как интерпретировать результат

Если получили:

```text
VaR95 = 320 000 RUB
```

Это не означает:

```text
Максимальный возможный убыток = 320 000 RUB
```

Правильная интерпретация:

```text
В 95% сценариев убыток не превышает 320 000 RUB.
В 5% худших сценариев он может быть больше.
```

VaR ограничен тем, что не показывает глубину хвоста. Например, два портфеля могут иметь одинаковый VaR95, но у одного в худших сценариях убытки будут 400 000 RUB, а у другого 2 000 000 RUB.

---

## 9. Проверка качества расчета

Для практического использования нужно проверять:

1. Достаточность истории.
2. Учет дивидендов и сплитов.
3. Отсутствие look-ahead bias.
4. Реалистичность ковариаций.
5. Чувствительность к количеству сценариев.
6. Стабильность VaR на разных периодах.
7. Backtesting: сколько раз фактический убыток превысил VaR.

---

## 10. Ошибка Monte Carlo

Классический Monte Carlo сходится медленно:

\[
\epsilon \sim O\left(\frac{1}{\sqrt{N}}\right)
\]

Если увеличить количество сценариев в 100 раз, ошибка уменьшится примерно только в 10 раз.


---

## 11. Что можно улучшить

Базовую модель можно расширить:

- GARCH для волатильности;
- copula-модели для зависимости активов;
- факторная модель рынка;
- стресс-сценарии;
- block bootstrap;
- regime switching;
- separate model для кризисных периодов;
- учет ликвидности и гэпов;
- учет валютного риска.

## 13. Краткий вывод

Monte Carlo VaR — это базовый и понятный способ оценить границу плохих сценариев портфеля. Для портфеля российских акций он реализуется достаточно просто: строится распределение доходности портфеля, переводится в распределение убытков, после чего берется нужный квантиль.

Главный недостаток метода — медленная сходимость и слабое описание хвоста. Поэтому для полноценного риск-анализа VaR обычно дополняют CVaR.
